# 03_ART_BIBLE.md

## Visual Goal

Readable industrial automation. and defensible against alien threats. with a clear and consistent visual language that communicates the function and purpose of each building and unit.

## Camera

2D isometric.
Slight perspective.
Wide zoom range.

## Visual Priorities

1. Readability
2. Clarity
3. Consistency
4. Beauty

## Shape Language

Production = Square
Storage = Rectangle
Power = Circular
Military = Angular
transportation = triangle
player = star
enemy = hexagon
alies = pentagon

## Color Language

Iron = Gray
Copper = Orange
Power = Yellow
Enemy = Red
boss = Purple
Player = Blue
alies = green

## UI Philosophy

Industrial
Minimal
Functional

## Asset Rules

All assets must:

- Match palette
- Match scale
- Match camera angle
- Match lighting

## Animation Rules

Feedback must communicate:

- Input
- Processing
- Output
- Failure

## Effects

Subtle.
Readable.
Never obscure gameplay.
