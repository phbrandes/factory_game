# 05_ASSET_PIPELINE.md

## Production Workflow

Greybox
→ Placeholder
→ Functional Prototype
→ Concept Art
→ Production Asset
→ Polish

## Recommended Tools

UI:

- Google Stitch
- Godot 4.4+ UI System

Concept Art:

- AI image generation
- itch.io premade concept art packs

Sprites:

- Aseprite
- Krita
- Godot 4.4+ Sprite2D
- Godot 4.4+ AnimatedSprite2D

## AI Workflow

1. Generate moodboards
2. Generate concept sheets
3. Create asset bible references
4. Produce final assets
5. Import into Godot

- Scale
- Camera angle
